# lead-parser

Локальный парсер бизнесов с Яндекс.Карт с техническим аудитом сайтов и отправкой результата в Telegram.

## Что делает

- Собирает карточки организаций по городу и запросу.
- Берёт название, адрес, телефон, рейтинг, число отзывов, сайт и ссылку на карточку.
- Фильтрует по `--min-reviews`.
- Асинхронно проверяет сайты: HTTP-статус, HTTPS, `meta name="viewport"`, время ответа.
- Ставит Priority:
  - `A` - сайта нет, указана соцсеть/мессенджер или сайт не открывается;
  - `B` - сайт открывается, но нет HTTPS, нет viewport или ответ дольше 4 секунд;
  - `C` - сайт технически исправен.
- Дописывает новые строки в `D:\учеба\PVL\БАЗА.csv` в UTF-8-SIG.
- Не создаёт дубли по последним 9 цифрам телефона или по названию+адресу.
- Сохраняет ручные колонки `Статус_звонка` и `Заметки`.
- Отправляет сводку и CSV в Telegram через `PARSER_BOT_TOKEN` на `ADMIN_ID`.

## Установка на Windows

```bat
cd D:\учеба\PVL\Проекты\lead-parser
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
copy .env.example .env
notepad .env
```

В `.env` нужно заполнить только `PARSER_BOT_TOKEN` и `ADMIN_ID`. Остальные значения уже заданы.

## Запуск

```bat
python main.py --city "Молодечно" --query "автосервис" --limit 30 --min-reviews 20
```

Тестовый прогон:

```bat
python main.py --city "Молодечно" --query "автосервис" --limit 8 --min-reviews 20
```

## Поведение при капче

Если Яндекс показывает капчу, парсер не падает: он останавливает сбор, сохраняет уже собранные лиды в CSV и отправляет отчёт в Telegram. В сводке будет предупреждение.

## Если изменилась разметка Яндекс.Карт

Парсер опирается на ссылки `/org/`, `aria-label`, `tel:`, микроразметку и текстовые маркеры. При изменении разметки запустите с `HEADLESS=false`, чтобы увидеть страницу, и проверьте селекторы в `yandex_maps.py`.
