# lead-parser

Локальный парсер бизнесов с Яндекс.Карт с техническим аудитом сайтов, хранением в Excel и отправкой результата в Telegram.

## Что делает

- Собирает карточки организаций по городу и запросу.
- Берёт название, адрес, телефон, рейтинг, число отзывов, сайт и ссылку на карточку.
- Фильтрует по `--min-reviews`.
- Асинхронно проверяет сайты: HTTP-статус, HTTPS, `meta name="viewport"`, время ответа.
- Ставит Priority:
  - `A` - сайта нет, указана соцсеть/мессенджер или сайт не открывается;
  - `B` - сайт открывается, но нет HTTPS, нет viewport или ответ дольше 4 секунд;
  - `C` - сайт технически исправен.
- Читает текущую базу из `D:\учеба\PVL\БАЗА.xlsx`, добавляет только новые строки и сохраняет ручные колонки `Статус_звонка` и `Заметки`.
- Не создаёт дубли по последним 9 цифрам телефона или по названию+адресу.
- Сортирует всю таблицу: сначала Priority `A`, затем `B`, затем `C`; внутри группы - по количеству отзывов по убыванию.
- Перезаписывает `БАЗА.xlsx` с полным оформлением через `openpyxl`.
- Отправляет в Telegram сводку и актуальный файл `БАЗА.xlsx`.

## Первый запуск и миграция

Если `D:\учеба\PVL\БАЗА.xlsx` ещё не существует, при первом сохранении парсер:

1. читает старый `D:\учеба\PVL\БАЗА.csv`;
2. переносит все строки в `БАЗА.xlsx`;
3. удаляет старый `БАЗА.csv`.

Если Excel-база уже есть, CSV больше не используется.

## Оформление Excel

При каждом сохранении файл создаётся заново с оформлением:

- тёмная шапка `#1E293B`, белый жирный шрифт, высота 28;
- закрепление первой строки и автофильтр по всей таблице;
- цвета Priority: `A` - `#FEE2E2`/`#991B1B`, `B` - `#FEF3C7`/`#92400E`, `C` - `#DCFCE7`/`#166534`;
- `HTTPS` и `Viewport`: `Нет` - `#FEE2E2`, `Да` - `#DCFCE7`;
- `Статус_звонка` и `Заметки` - светло-голубой фон `#F0F9FF`;
- выпадающий список статусов звонка: `Новый`, `Не дозвонился`, `Отправил демо`, `Думает`, `Созвон`, `Отказ`, `Сделка`;
- `Сайт` и `Ссылка_на_карточку` - кликабельные гиперссылки;
- тонкие серые границы `#CBD5E1`, выравнивание по вертикали по центру, перенос текста, высота строк 24;
- автоширина колонок, для `Адрес` и `Заметки` - не более 35.

## Установка на Windows

```bat
cd D:\учеба\PVL\Проекты\lead-parser
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
copy .env.example .env
notepad .env
```

В `.env` нужно заполнить только `PARSER_BOT_TOKEN` и `ADMIN_ID`. Путь к базе задаётся в `LEADS_XLSX_PATH` и по умолчанию равен `D:\учеба\PVL\БАЗА.xlsx`.

## Запуск

```bat
python main.py --city "Молодечно" --query "автосервис" --limit 30 --min-reviews 20
```

Тестовый прогон:

```bat
python main.py --city "Молодечно" --query "автосервис" --limit 8 --min-reviews 20
```

## Поведение при капче

Если Яндекс показывает капчу, парсер не падает: он останавливает сбор, сохраняет уже собранные лиды в Excel и отправляет отчёт в Telegram. В сводке будет предупреждение.

## Если изменилась разметка Яндекс.Карт

Парсер опирается на ссылки `/org/`, `aria-label`, `tel:`, микроразметку и текстовые маркеры. При изменении разметки запустите с `HEADLESS=false`, чтобы увидеть страницу, и проверьте селекторы в `yandex_maps.py`.
