# Пульт в кармане

Telegram-бот для управления файлами `Карточки/`, `ДЕЛА.md` и `ПУЛЬТ.md`
в рабочей папке `WORKSPACE_DIR`.

## Запуск

1. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`, `DEEPSEEK_API_KEY`.
2. Убедитесь, что `WORKSPACE_DIR` указывает на корень проекта PVL.
3. Проверьте DeepSeek:
   - `DEEPSEEK_BASE_URL=https://api.deepseek.com` (или `https://api.deepseek.com/v1`)
   - `DEEPSEEK_MODEL=deepseek-chat`
4. Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

5. Запустите бота:

```bash
python bot.py
```

## Команды

- `/pult` - при `GIT_SYNC=true` делает `git pull --rebase`, запускает `собрать.py` и присылает `ПУЛЬТ.md`.
- `/card <часть имени>` - ищет карточку в `Карточки/` и присылает её текст.
- Обычный текст - DeepSeek понимает формат `По <Компания>: ...` и свободную форму
  (`Позвонил в Автоэкспресс, перезвонить через 7 дней`, `Имя: Иван, телефон: ...`).
  Если карточки ещё нет, бот создаёт её с разделами: название и город, контакт,
  сайт и соцсети, статус воронки, история касаний, следующий шаг.
- После любой правки бот пишет запись в журнал, пересобирает `ПУЛЬТ.md`, а при
  `GIT_SYNC=true` делает `git add`, `git commit`, `git pull --rebase` и `git push`.
- Утренний дайджест - каждый день в 09:00 по `TIMEZONE` (по умолчанию `Europe/Minsk`).

## Ошибки

Любая ошибка API, парсинга ответа, записи файла или git-операции возвращается
в Telegram сообщением `Ошибка: <текст>`, бот не молчит.

Все ответы в Telegram проходят через функцию `safe_answer`/`safe_send`,
которая принудительно заменяет длинные тире на обычный дефис.
