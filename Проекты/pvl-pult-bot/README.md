# Пульт SAMOLA CRM

Telegram-бот для работы с таблицей
[SAMOLA CRM](https://docs.google.com/spreadsheets/d/16JYC1URl2anD0rEDogs37ZV2aej3O1wLDR1F_K1z2ro/edit)
напрямую через Google Sheets API. Без `git pull`, без `ПУЛЬТ.md` и без Markdown-таблиц.

## Что умеет

- Читает вкладки `Лиды`, `Дела`, `История` через `gspread.open_by_key`.
  Google Drive API не нужен: включён только Google Sheets API.
- Постоянная клавиатура 2x3 (`resize_keyboard`, `is_persistent`) всегда у поля ввода:

  | Сегодня | Горячие | Просрочено |
  |---|---|---|
  | Неделя | Дела | Сводка |

- `/start` и `Сводка` присылают короткую текстовую сводку дня с этой клавиатурой.
  Нажатие любой кнопки сначала присылает короткую шапку среза (`Горячие (4)`),
  затем карточки.
- Срезы: `Сегодня`, `Горячие` (Горячий / Переговоры / Демо готово), `Просрочено`
  (дата строго меньше сегодня), `Неделя` (7 дней), `Дела` (активные задачи).
- Карточка лида - не больше 4 строк, чистый Telegram HTML: компания (город) - статус,
  дата/время и кликабельный телефон, короткий шаг, ссылка на демо/КП.
  Длинные тире, палки `|`, `<details>` и `<a href="tel:...">` не используются.
- Кнопки под карточками зависят от даты (Europe/Minsk):
  - лид с датой `<= сегодня` (или без даты): `Сделано`, `+1 день` и `Бриф`,
    если заполнены заметки;
  - лид с будущей датой: только `Действия / Бриф`. Кнопка раскрывает блок брифа
    и даёт `На сегодня`, `+1 день`, `Закрыть досрочно`, `Свернуть`;
  - дело с дедлайном `<= сегодня`: `Сделано` и `+1 день`;
  - дело с будущим дедлайном: только `Сделано` (можно закрыть досрочно).
- `Сделано` у лида пишет шаг в `Историю` и очищает `След. дата` / `Время` без удаления
  строк. У дела ставит статус `Выполнено` и тоже пишет строку в `Историю`.
- Обновление CRM текстом и голосом (только владелец из `ADMIN_ID` / `ALLOWED_USER_IDS`):
  - голосовые `.ogg` распознаёт локальный `faster-whisper` (tiny/base, CPU, язык ru,
    модель кэшируется в памяти процесса, платные ключи не нужны);
  - распознанный текст и компактный список лидов и активных дел уходят в DeepSeek
    (`DEEPSEEK_API_KEY`, JSON-режим);
  - модель возвращает `update_lead` / `add_task` / `update_task` / `unknown`;
  - бот присылает HTML-превью и кнопки `Подтвердить` / `Отмена`;
  - запись в таблицу идёт только после `Подтвердить`, изменённые шаги дублируются
    в `Историю`, строки не удаляются, блок «Сводка показателей CRM» не затрагивается.
- Планировщик Europe/Minsk:
  - утренняя сводка в 08:30 (звонки и дела на сегодня + клавиатура);
  - напоминание за 15 минут до звонка без дублей (`.state/reminders_sent.json`);
  - ежедневный JSON-бэкап всех 3 вкладок в `backups/`, хранятся последние 14 файлов.

## Настройка

1. Положите JSON-ключ service account в `D:\учеба\PVL\tools\google_creds.json`
   (на VPS: `/opt/pvl-workspace/tools/google_creds.json`).
2. Скопируйте `.env.example` в `.env` и заполните:

```env
BOT_TOKEN=...
ADMIN_ID=...
# ALLOWED_USER_IDS=...
GOOGLE_CREDS_PATH=D:\учеба\PVL\tools\google_creds.json
SPREADSHEET_ID=16JYC1URl2anD0rEDogs37ZV2aej3O1wLDR1F_K1z2ro
BACKUPS_DIR=backups
TIMEZONE=Europe/Minsk
DEEPSEEK_API_KEY=sk-...
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
WHISPER_MODEL=tiny
WHISPER_LANGUAGE=ru
```

Если `DEEPSEEK_API_KEY` не задан в `.env` бота, он ищется в корневом `.env`
рабочей папки и в `.env` соседних проектов. Без ключа бот работает кнопками,
а текстовые и голосовые обновления отвечают понятной ошибкой.

3. Дайте service account доступ к таблице (роль «Редактор») и включите Google Sheets API
   в проекте `airy-discovery-515814-e6`.

## Установка и запуск

```bash
python -m pip install -r requirements.txt
python test_ui.py          # кнопки и рендер: лид на сегодня, лид на 27.11, будущее дело
python test_ai_parser.py   # ИИ-парсер на моке DeepSeek, без записи в таблицу
python test_sheets.py      # чтение 3 вкладок и HTML-карточек
python bot.py
```

Все три теста ничего не пишут в таблицу и не отправляют сообщения в Telegram.

### Голос и ffmpeg

`faster-whisper` декодирует `.ogg` через PyAV (ffmpeg-библиотеки внутри wheel),
поэтому системный `ffmpeg` не обязателен. Модель скачивается один раз в
`models/` рядом с ботом (или в `WHISPER_DOWNLOAD_ROOT`) и дальше живёт в памяти.
