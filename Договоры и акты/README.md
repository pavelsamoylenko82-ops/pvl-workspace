# Договоры и акты

Здесь хранятся договоры, акты, счета и допсоглашения по клиентам.

## Схема именования файлов

`01 Бизнес (Имя), договор/акт/счёт/допсоглашение, сумма.docx`

- `01` - порядковый номер документа в папке клиента.
- `Бизнес` - название компании.
- `(Имя)` - имя контактного лица или руководителя.
- `договор/акт/счёт/допсоглашение` - тип документа.
- `сумма` - твердая сумма с валютой, например `1200 BYN`.

Примеры:

```text
01 Stimul (Наталья), договор, 1200 BYN.docx
01 Stimul (Наталья), счёт, 600 BYN.docx
02 Stimul (Наталья), акт, 600 BYN.docx
02 Stimul (Наталья), допсоглашение, 240 BYN.docx
```

## Чек-лист перед отправкой

- [ ] Реквизиты клиента сверены: название, УНП, адрес, банк, расчётный счёт.
- [ ] Сумма совпадает с КП, `ЦЕНЫ.md` и карточкой клиента.
- [ ] В договоре сумма только твердой цифрой в BYN, без «от» и «примерно».
- [ ] Внешние расходы вынесены отдельно.
- [ ] Этапы, сроки и порядок оплаты заполнены.
- [ ] Указано, что не входит в работы.
- [ ] Проверен чат и получатель: документ уходит в нужный диалог.
- [ ] Файл открывается, имя соответствует схеме.
- [ ] В документе нет паролей, токенов и API-ключей.
- [ ] Копия документа сохранена в этой папке.
