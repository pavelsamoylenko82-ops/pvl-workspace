## systemd

- Служба: `pvl-pult.service`
- Файл службы: `/etc/systemd/system/pvl-pult.service`
- Автозапуск: включён
- Политика перезапуска: `Restart=always`, `RestartSec=5`

Основные команды:

```bash

systemctl restart pvl-pult
systemctl stop pvl-pult

systemctl daemon-reload
```

```bash

```

Проверка после изменения unit-файла:

```bash

systemctl status pvl-pult --no-pager
```

## Примечание по .env

В `.env.example` репозитория используются старые имена `LLM_API_URL`, `LLM_API_KEY`, `LLM_MODEL`.
Текущий `config.py` ожидает `DEEPSEEK_BASE_URL`, `DEEPSEEK_API_KEY`, `DEEPSEEK_MODEL`.
На сервере добавлены совместимые алиасы `DEEPSEEK_*` на основе заполненных `LLM_*`.
