# Правила работы DeepSeek CLI (SAMOLA Studio)

## Контекст и стек
- Корень рабочей папки: D:\учеба\PVL.
- Всегда перед началом работы по клиенту читай его карточку в Карточки/ и историю в Клиенты/<клиент>/ПАМЯТЬ.md.
- Секреты, токены и пароли хранить строго в .env и ДОСТУПЫ.md. Никогда не выводить их в код, Git и вывод терминала.

## Стандарты сайтов и демо (2026)
- Перед вёрсткой и редизайном читай skills/design-unslop.md, skills/motion-gsap-webgl.md и skills/commercial-site-gate.md.
- Запрещено делать «сайты из 2015 года»: острые углы 0px, плоские серые рамки 1px как основу, монохромные палитры без контрастного акцента, статичные страницы без движения и плоские 3D-повороты фото (rotateY/rotateX).
- Стандарт по умолчанию: скругления rounded-full / rounded-2xl / rounded-3xl, база + 1 неожиданный акцент (до 10% экрана), связка GSAP + ScrollTrigger + Lenis (на десктопе), соблюдение prefers-reduced-motion, base: './', запрет длинных тире.
- На демо и живых сайтах никаких выдуманных цен, отзывов и цифр.

## Откат и проверка
- Перед крупными правками обязательно делай коммит в Git для отката.
- Проверка через Playwright: 0 ошибок консоли, scrollWidth <= clientWidth на 360px и 1440px, все картинки загружены, формы/квизы работают.
