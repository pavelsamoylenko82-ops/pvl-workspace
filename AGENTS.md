# Правила работы DeepSeek CLI (SAMOLA Studio)

## Контекст и стек
- Корень рабочей папки: D:\учеба\PVL.
- Единая CRM-база - Google Sheets «SAMOLA CRM» (вкладки Лиды, Дела, История):
  https://docs.google.com/spreadsheets/d/16JYC1URl2anD0rEDogs37ZV2aej3O1wLDR1F_K1z2ro/edit

- Запись в CRM выполняет Telegram-бот «Пульт» (Проекты/pvl-pult-bot): текст, голос или кнопки. Руками в таблицу пиши только по прямой просьбе.
- Секреты, токены и пароли хранить строго в .env и ДОСТУПЫ.md. Никогда не выводить их в код, Git и вывод терминала.

## Стандарты сайтов и демо (2026)
- Перед вёрсткой и редизайном читай skills/design-unslop.md, skills/motion-gsap-webgl.md и skills/commercial-site-gate.md.
- Запрещено делать «сайты из 2015 года»: острые углы 0px, плоские серые рамки 1px как основу, монохромные палитры без контрастного акцента, статичные страницы без движения и плоские 3D-повороты фото (rotateY/rotateX).
- Стандарт по умолчанию: скругления rounded-full / rounded-2xl / rounded-3xl, база + 1 неожиданный акцент (до 10% экрана), связка GSAP + ScrollTrigger + Lenis (на десктопе), соблюдение prefers-reduced-motion, base: './', запрет длинных тире.
- На демо и живых сайтах никаких выдуманных цен, отзывов и цифр.

## Сборка демо-сайтов
- Один лёгкий шаблон на все демо: копируй готовый каркас, меняй контент, палитру и акцент. Не изобретай структуру заново под каждый заказ.
- Без тяжёлых прогонов автотестов, скриншотных батарей и лишнего рефакторинга ради демо. Проверка - быстрая: страница открывается, 0 ошибок консоли, нет горизонтального скролла на 360px и 1440px, картинки на месте.
- Деплой и любые временные сборки - строго через D:\учеба\PVL\_deploy\ (там же готовые папки для GitHub Pages). В корне рабочей папки сборок не создавать.

## Откат и проверка
- Перед крупными правками обязательно делай коммит в Git для отката.
- Для живых сайтов (не демо) - полная проверка: 0 ошибок консоли, scrollWidth <= clientWidth на 360px и 1440px, все картинки загружены, формы/квизы работают.
